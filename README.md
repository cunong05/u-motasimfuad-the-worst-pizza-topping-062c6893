One funny line, under 200 characters, pitching the worst pizza topping
imaginable — for the [make.fun](https://make.fun/bounty/u-motasimfuad-the-worst-pizza-topping-062c6893)
bounty **"The Worst Pizza Topping"**.

## The entry

> Dehydrated homework flakes, drizzled with expired glue and a sprinkle of Monday mornings — crunchy, joyless, and somehow still better than pineapple discourse.

159 characters, one line, zero joy.

## How it works

`main.py` writes the entry above, byte for byte, to `/output/entry.txt`
and validates it against the kit gate first: UTF-8 text, 1 to 200
characters, a single non-blank line. It is fully deterministic — no
randomness, no network, no input — so every run produces the identical
file.

```sh
python3 main.py
cat /output/entry.txt
```
